# morphicons · Native motion lab

A responsive Flutter example using the local package, with eight stroke/fill pairs, spring presets, interruption, deterministic scrubbing and reduced-motion controls. No third-party runtime dependencies.

```bash
flutter pub get
flutter run -d chrome
# or: flutter run -d windows / android / ios / macos / linux
flutter test
# Optional: capture all 24 quarter/half/three-quarter native frames.
flutter test --dart-define=CAPTURE_VISUALS=true
# Contact sheet: build/verification/midframes.png
flutter build web --release
```

Platform runners are generated by Flutter; iOS/macOS builds need macOS and Xcode, and Windows builds need the Visual Studio C++ toolchain. Use `flutter devices` to list locally available targets.

See the [package README](../README.md) for APIs, lifecycle and geometry limits.
